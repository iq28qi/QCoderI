# AETHER Motion Studio в QCoderI

Выберите профиль **AETHER Motion Studio** в новом диалоге с рабочей папкой. Выбранные модель и уровень мышления используются обычным маршрутом QCoderI.

Инструменты профиля

- `aether_status` обнаруживает открытые редакторы и возвращает идентификаторы сессий.
- `aether_open` запускает установленный `AetherMotionStudio.exe` и ожидает локальный API.
- `aether_tools` показывает возможности подключённой версии. Параметр `method` возвращает схему конкретной команды.
- `aether_command` выполняет команды общего документа, включая транзакции, историю и сохранение.
- `aether_viewport` возвращает изображение текущего viewport в чат.

Пример задачи для агента

> Подключись к AETHER, создай куб, задай ключи перемещения и сохрани проект в рабочую папку. Проверь сцену и покажи кадр viewport.

Для установки в другом каталоге передайте `app_directory` инструменту либо задайте переменную окружения `QCODERI_AETHER_HOME`. Обнаруживаются `.runtime` в каталоге приложения и в `dist/AetherMotionStudio`. При нескольких открытых редакторах передавайте `session` из `aether_status` каждому вызову.

Команды возвращают версии документа. Передавайте `expected_revision` при изменениях. После ошибки с `ambiguous=true` получите состояние сцены перед повторным действием. `system.batch` объединяет поддерживаемые редактором обратимые операции в одну транзакцию. Несколько исполнителей могут использовать ресурс команды `aether-editor` для последовательной записи в общий документ.

Поддержка операций определяется через API редактора. В AETHER 0.1 доступны OBJ, трансформации объектов, трансформ-ключи, сохранение `.aemotion` и структурные проверки. Разработка скелета, AutoRig, skinning, IK, физики и Unreal продолжается в AETHER.

Локальная интеграция использует Windows named pipe и токен сессии из metadata редактора. Python для подключения QCoderI к упакованному AETHER отдельно устанавливать не требуется.

Установка профиля в существующий QCoderI выполняется командой `node harness-base/scripts/install-aether-profile.mjs`. Параметр `--home` выбирает каталог данных QCoderI. Новый профиль становится доступен при открытии списка профилей нового диалога. Сборочный конвейер также включает AETHER в профили команды, 3D Studio и Unreal Engine.
