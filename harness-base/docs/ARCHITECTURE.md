# Устройство основы

Лаунчер `QCoderI.exe` собран из `scripts/launcher.c` как Windows GUI-программа. Он разрешает путь относительно своего EXE и запускает `harness-base/app/QCoderI.exe`, не создавая консоль. Путь и аргументы с пробелами поддерживаются.

В `app` находится полный поставляемый Electron, в `app/resources/app.asar` — пересобранный код из `source`. Нативные `.node`, `.dll` и вспомогательные `.exe` размещаются в `app.asar.unpacked`, сохраняя относительные пути. `build.py` пересчитывает хеши архива и runtime-дескриптор.

Перед запуском сервера главный процесс задаёт собственное имя приложения, AppUserModelID, папку Electron и `DSH_HOME`. По умолчанию данные находятся в соседней папке `data`; для изолированных проверок можно задать существующую переменную `DSH_HOME`.

Интерфейс использует штатный реестр локализации. Русский язык добавлен как отдельный язык, а словари русского строятся при регистрации модулей из таблицы переводов. Для внутренних идентификаторов, JSON, команд и имён моделей перевод не применяется.

Настройка `system-prompt.text` зарегистрирована через файловый сервис настроек. Поле в настройках обращается к существующему settings API с номером ревизии, чтобы замечать конкурирующие изменения. Текст добавляется отдельной секцией без интерполяции `{{...}}`. Снимок хранится по объекту живого диалога и не меняется посреди его работы. Дочерние агенты берут снимок живого родителя по `parentSession`, поэтому изменение настройки между запуском ведущего и исполнителя не разделяет команду на разные версии инструкций. Наследуется только пользовательская секция; остальные секции и права собираются штатным механизмом каждого агента.

Windows-процессы, создаваемые нативным исполнителем, получают `CREATE_NO_WINDOW`. Существующие флаги приостановки, Unicode-окружения, Job Object, стандартные потоки и отмена сохраняются. Обычные фоновые Node-процессы получают `windowsHide: true`.

Неиспользуемая соседняя копия Hermes Agent из исходной папки не является зависимостью этого приложения. Основа содержит файлы, которые действительно использует запущенный DeepSeek Harness.
