# Создание изображений во время работы

Рабочая модель в «Проектах» получает инструмент `generate_image` и инструкции сама использовать его, когда задаче нужна фотография, иллюстрация, фон, текстура или другой растровый материал. Текстовая модель остаётся выбранной для работы, а генерация идёт через отдельный API изображений NiceAI. В обычном «Общении» инструменты отключены.

Выбор ограничен двумя запрошенными моделями:

| Задача | Выбор по умолчанию |
| --- | --- |
| Новая картинка | `seedream-5.0-pro`, 2K |
| Правка одного изображения | `krea-k3-edit`, 1K |
| Несколько референсов | `seedream-5.0-pro`, до 14 |

Это практический выбор для разных задач, а не утверждение о единственном победителе по любому критерию. [Документация Krea описывает Seedream 5 Pro как модель высшего качества с точным управлением правкой](https://www.krea.ai/docs/api-reference/image/seedream-5-pro), а [Krea 3 — как быстрый редактор, следующий инструкциям](https://www.krea.ai/docs/developers/krea-3/overview). При сложной правке агент может явно выбрать Seedream и с одним референсом. Пользователь может указать одну из этих двух моделей; другие генераторы инструмент не принимает.

В актуальном авторизованном каталоге NiceAI обе модели доступны. Подключение выбирается среди настроенных маршрутов `https://api.niceai.rest`; если текущая рабочая модель уже использует NiceAI, её подключение имеет приоритет. Секрет берётся через штатный сервис credentials. Пользовательские настройки и список моделей не переписываются.

## Запрос и результат

Инструмент принимает `prompt`, необязательные `model`, `resolution` (`1K`/`2K`), `caption` и `reference_images`. Референсы — идентификаторы изображений текущего диалога; для файла проекта агент сначала вызывает `read_image`. Чужой идентификатор вложения отклоняется. NiceAI получает фактические байты референсов через data URL.

По [документации NiceAI](https://api.niceai.rest/docs) используется `GET /v1/images/models` и `POST /v1/images/generations`, а не маршрут текстового чата. Передаются выбранная модель, описание, разрешение, `n: 1`, `response_format: b64_json` и при наличии `reference_images`. Каталог проверяется с ключом подключения и кешируется на минуту с учётом отпечатка ключа. Лимит референсов сверяется с каталогом конкретного шлюза; для Krea NiceAI сейчас разрешает одно изображение.

Ответ сохраняется в AttachmentStore и возвращается модели как изображение. Карточка «Изображение» видна в чате даже при свёрнутой истории инструментов, поддерживает крупный просмотр и сохраняется в истории. Если доступно отображение хостового файла в рабочее окружение, результат также содержит `path`: агент может скопировать файл в проект штатной оболочкой, соблюдая её ограничения. Нормализованный файл хранится без обычного расширения; при копировании в проект агент должен выбрать расширение по `mediaType` результата.

## Повторы

В `data/image-jobs` хранится журнал. Одинаковый запрос в одном ходе одного диалога повторно не оплачивается: возвращается сохранённое изображение. Если POST завершился неопределённо, автоматическая повторная постановка в этом ходе блокируется. Готовый ответ сохраняется до загрузки, поэтому сбой скачивания позволяет повторить только загрузку. При перенаправлении на CDN ключ NiceAI не передаётся. Отмена останавливает ожидание; она не обещает отменить генерацию, уже принятую провайдером.

Изменение одной подписи использует уже созданное изображение и возвращает новую подпись без новой генерации. Если предпочтительное подключение не имеет ключа, не отвечает на чтение каталога или не предоставляет модель, перед отправкой генерации проверяются другие настроенные подключения NiceAI. После отправки платного запроса переключения на другой маршрут нет.

## Проверки

`tests/image-generation-native.mjs` выполняет настоящий AgentLoop и инструменты с перехваченным HTTP: создание через Seedream, правку через Krea, возврат пикселей модели, путь к сохранённому файлу, ограничения референсов, журнал повторов, неопределённый сбой POST, повтор скачивания и отсутствие ключа на CDN. `tests/screenshots-native.mjs` и UI smoke проверяют, что инструкции о демонстрационных снимках доходят до модели без отдельной команды на скриншот.

Отдельно выполнены два настоящих запроса через существующее подключение NiceAI: Seedream создала фотографию синей кружки 2048×2048, затем Krea получила её байты как референс и изменила цвет кружки на зелёный, вернув 1024×1024. Оба файла визуально проверены; пользовательские изображения и переписки для проверки не использовались.

Код: `assets/team/image-generation.js`; подключение и галерея воспроизводятся через `scripts/apply-screenshots.py` и `scripts/build.py`.
